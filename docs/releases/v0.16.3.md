# v0.16.3: manual login accepts Copy as cURL exports

### Fixed

- Cookies from a DevTools "Copy as cURL" export reach manual login even when the command carries them in `-b` or `--cookie`. The parser previously treated the entire command as a cookie string, which produced malformed names and failed later in the HTTP client. Inputs that are still not recognized now fail with a message listing the accepted formats (#403).

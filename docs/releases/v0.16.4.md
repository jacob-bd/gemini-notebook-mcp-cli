# v0.16.4: login storage question works on Typer 0.29

### Changed

- The CLI and MCP server reach shared core primitives only through the service layer. A new test fails on any direct `core/` import, so the boundary stays enforced (#405).

### Fixed

- `nlm login` asked the new-login plain-or-protected question with a Click range type. Typer 0.29 no longer accepts that type, so the question ended the command with a bare `AssertionError`, and Typer 0.26 to 0.28 stopped on an out-of-range answer instead of asking again. The question now reads the number itself and repeats with "Please enter 1 or 2." until the answer is valid. Enter still chooses protected ([#406](https://github.com/jacob-bd/gemini-notebook-mcp-cli/issues/406), [#407](https://github.com/jacob-bd/gemini-notebook-mcp-cli/pull/407)).

# v0.16.5: cookie file imports prefer `.google.com` values

### Fixed

- `nlm login --file` now prefers the `.google.com` cookie when the same name appears on several Google domains in a Netscape or JSON export. Previously the last entry won, so an "export all cookies" file could save the `.youtube.com` values of `SID`, `HSID`, `SSID`, `APISID`, and `SAPISID`. The names were present, so validation passed, and the wrong values were then sent to Gemini Notebook. Imports now use the same domain preference as browser-exported cookies ([#408](https://github.com/jacob-bd/gemini-notebook-mcp-cli/issues/408), [#409](https://github.com/jacob-bd/gemini-notebook-mcp-cli/pull/409)).
